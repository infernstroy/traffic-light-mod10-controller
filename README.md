# Design and Simulation of a Traffic-Light Controller Using a MOD-10 Counter

A Digital Logic Circuits (DLC) capstone project. A 4-bit **synchronous MOD-10 (decade) counter** counts 0 → 9 and repeats. A small **combinational decoder** turns the count into a RED, GREEN or YELLOW light. An interactive website simulates it, and `DESIGN.md` documents the design.

## Features
- Three-lamp traffic light with smooth fade transitions
- Live Q3 Q2 Q1 Q0 bits, binary value, decimal count, phase name, clock-pulse counter
- Start, Pause, Reset, manual **Next clock pulse**, adjustable speed
- Truth tables (state transitions, light decoding, valid/invalid states) generated by the same code the simulator runs
- Circuit diagram and block diagram (SVG)
- Plain-language learning section
- Automated tests (`node tests/test.js`)

## Technologies
HTML, CSS and vanilla JavaScript. No frameworks, build step, backend or paid services. Tests use Node.js (optional).

## How the counter works
Four D flip-flops (Q3 Q2 Q1 Q0) share one clock, so the counter is **synchronous** (not a ripple counter). Before each clock edge, gates compute the next value:

```
A = Q1·Q0     B = Q2·Q1·Q0     T = Q3·Q0 (true at count 9)
D0 = Q0'·T'              D1 = (Q1 ⊕ Q0)·T'
D2 = (Q2 ⊕ A)·T'         D3 = (Q3 ⊕ B)·T'
```
At count 9 (1001), T = 1 forces every D input to 0, so the next clock edge loads 0000. Reset is a manual asynchronous clear.

## Traffic-light timing
| Counts | Light | Clock pulses |
|---|---|---|
| 0–2 | RED | 3 |
| 3–7 | GREEN | 5 |
| 8–9 | YELLOW | 2 |

The counter has **10 states**; the light has **3 phases** that group those states. Decoder: `RED = (Q3+Q2+A)'`, `GREEN = Q3'·(Q2+A)`, `YELLOW = Q3`.

1. Download or clone the repository.
2. Double-click `index.html` (any modern browser). No server needed.
3. Optional tests: install Node.js, open a terminal in the project folder, run `node tests/test.js`.

## Deploy on GitHub Pages
1. Push the files to a public repository.
2. Repository **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, **Branch** `main`, folder `/ (root)`, then **Save**.
4. Wait 1–2 minutes. The URL appears at the top of the Pages screen: `https://<your-username>.github.io/<repository-name>/`.
