Design and Simulation of a Traffic-Light Controller Using a MOD-10 Counter

A 4-bit synchronous counter counts 0 to 9 and repeats. A small combinational decoder turns each count into RED, GREEN or YELLOW. Everything on this page is computed by the same gate-level logic described in DESIGN.md.

Counting cycle (MOD-10)

    Ten counter states, three light phases: RED = 3 pulses (0–2), GREEN = 5 pulses (3–7), YELLOW = 2 pulses (8–9).

    Counter bits and clock

    Four D flip-flops hold Q3 (weight 8), Q2 (4), Q1 (2) and Q0 (1). All four share the same clock, so on each rising edge they all load their new value together. That is what makes it a synchronous counter, not a ripple counter.

    Between clock edges nothing changes: the logic only prepares the next value on the D inputs.

    MOD-10 and the three phases

    The counter cycles through 10 states. The traffic light has 3 phases. The decoder groups the ten counts into phases of unequal length: 3 + 5 + 2 = 10 pulses. They are different things, and both repeat every 10 pulses.

    Next-state logic

    A  = Q1·Q0          B = Q2·Q1·Q0
T  = Q3·Q0          (true at count 9)
INC0 = Q0'          INC1 = Q1 ⊕ Q0
INC2 = Q2 ⊕ A       INC3 = Q3 ⊕ B
Di = INCi · T'      (T = 1 forces all D = 0)

    At count 9 (1001), T = 1 so every D input becomes 0 and the next clock edge loads 0000. This is a synchronous clear.

    Traffic-light decoding

    RED    = (Q3 + Q2 + A)'
GREEN  = Q3' · (Q2 + A)
YELLOW = Q3

    For counts 0–9 exactly one output is 1. Counts 10–15 never occur in normal operation; if power-up lands there, the counter returns to a valid state within 2 pulses (see the table below).

    What is a MOD-10 counter?

    A counter that has 10 states and then repeats. Here: 0 to 9, then back to 0. It is also called a decade counter.

    Why four flip-flops?

    Each flip-flop stores one bit. n flip-flops give 2n states. Three give 8, which is too few for 10. Four give 16, so we use 10 and skip 6.

    What is synchronous counting?

    All flip-flops get the same clock and change at the same moment. In a ripple counter each stage clocks the next, so changes ripple through with delay. This design uses a shared clock.

    How does the controller work?

    The counter keeps time in clock pulses. The decoder looks at the count and lights one lamp: RED for 0–2, GREEN for 3–7, YELLOW for 8–9.

    Why combinational decoding?

    The lamps depend only on the present count, with no memory needed. Gates are enough, and the output follows the count immediately.

    Real-life uses

    The same ideas appear in digital clocks, frequency dividers, event timers, and simple fixed-time traffic or machine controllers.
